# A25 Training Workspace

Public draft documentation for future A25 Roundtable and Pocket Server builders, model-training preparation, and cross-platform AI project handoffs. **This does not certify** a live working room, authenticated seat identities, complete transcripts, or implemented safeguards.

## Responsibilities
Zed makes decisions and grants approvals. GPT writes and commits. Claude independently reads and reviews. Agreement does not imply authorization.

## Read path
Claude can follow raw URLs appearing in Zed's conversation or in a fetched file; ordinary GitHub page navigation may fail. GPT supplies **one commit-pinned raw INDEX.md URL** for each review. The index pins its children to the prior content commit and includes SHA-256 checksums. The index is committed last and must itself be opened by its own commit SHA. A raw fetch alone does not prove version identity; check content hashes.

## Directories (planned or active)
- `governance/`: authority, attribution and working rules.
- `evidence/gpt/`, `evidence/claude/`, `evidence/zed/`: per-seat original-source references and custody metadata (planned).
- `case-studies/`: narrative analyses tied to original evidence (planned).
- `failure-catalog/`: one stable ID per observed failure (planned).
- `relay-tests/`: direction-specific parity tests (planned).
- `handoffs/`: source maps and resumption instructions (planned).
- `checkpoints/`: independently verifiable recovery snapshots (planned).
- `builder-requirements/`: proposed and approved implementation requirements (planned).
- `validation/`: tests and evidence of outcomes (planned).
- `source-manifests/`: hashes, origins and custody locations (planned).
- `living-record/`: ongoing status, decisions, unresolved items and supersession history (planned).
- `templates/`: machine-readable document skeletons.
