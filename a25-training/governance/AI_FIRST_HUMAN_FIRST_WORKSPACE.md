# AI-first repository, human-first presentation

Status: Zed-directed working principle, 2026-10-16. Exact message clock time not verified.

## Purpose
GitHub is both Zed's current portfolio and the shared, durable workspace for AI collaborators and future builders. The objective is to reduce manual copy/paste relay and preserve full-fidelity information across GPT, Claude, future A25 seats, projects, and eventual game development. Do not compress or silently summarize source evidence for AI-to-AI exchange.

## AI-first GitHub
- Store complete machine-readable text sources, Markdown, code, indexes, provenance, test records, decision history, and manifests in the A25 branch.
- Prefer commit-pinned raw links and stable IDs. Record source completeness, origin, and independent review status.
- AI seats should independently read actual committed records, not rely on a human's copied summary. Current tool and permission limitations must be stated, not concealed.
- GitHub supports binary assets, but current AI integrations may limit writing or reading them. Use accessible text sources as the operational interchange format.

## Zed-first output
- Explain work in clear conversational language. Provide PDF reading copies when Zed requests them, without making PDFs a prerequisite for repository preservation.
- Do not require Zed to download and re-upload artifacts when direct repository storage is possible.
- Preserve the full underlying source; a human-facing explanation may be shorter without replacing the archival record.

## Roundtable authority
Broad information access does not imply permission to approve, impersonate another seat, rewrite original evidence, or override Zed. GPT currently writes; Claude independently reviews on return. Future server access rules must be explicit and tested.

## Does not certify
This document does not establish automatic synchronization, unrestricted AI read/write permissions, or live Pocket Server recovery. These remain implementation and validation goals.
